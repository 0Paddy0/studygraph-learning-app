# iPhone Target

Target: native-feeling iPhone app using a shared Rust core.

Planned stack:

- React Native UI
- Rust core through UniFFI/native bridge
- SQLite local database

First mobile goal:

1. Open local workspace.
2. Show deck dashboard.
3. Review cards.
4. Persist SRS locally.
5. Import/export basic Markdown or StudyGraph JSON.

The first iPhone version should not try to clone the entire desktop editor. It should focus on capture, reading, review and simple block editing.

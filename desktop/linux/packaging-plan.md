# Linux Packaging Plan

## Phase 1

- Development build only.
- Run through Tauri dev command.

## Phase 2

- Produce AppImage.
- Store app data under XDG-compatible paths.
- Support importing/exporting Markdown folders.

## Phase 3

- Produce `.deb`.
- Evaluate Flatpak if distribution friction appears.

## Notes

The Linux app should not assume a specific desktop environment.

# Android Target

Target: native-feeling Android app using a shared Rust core.

Planned stack:

- React Native UI
- Rust core through UniFFI/native bridge
- SQLite local database

First mobile goal:

1. Open local workspace.
2. Show deck dashboard.
3. Review cards.
4. Persist SRS locally.
5. Import/export basic Markdown or StudyGraph JSON.

The first Android version should prioritize reliable review and local data over full desktop editing parity.
